# SMASH — 우리 학교 부수기

브라우저에서 바로 실행하는 3D 캠퍼스 파괴 미니 게임입니다. Three.js를 사용하며 별도의 설치나 빌드 도구가 필요하지 않습니다.

## 플레이

- 폭탄: 클릭한 건물 주변까지 폭발
- 야구 배트: 가까운 건물을 타격
- 레이저: 한 건물을 정밀 파괴
- 운석: 강력한 파괴 효과
- 초기화: 캠퍼스와 점수 초기화

마우스 왼쪽 버튼으로 건물을 클릭하세요. 마우스 오른쪽 버튼을 누른 채 드래그하면 카메라를 회전하고, 휠로 확대/축소할 수 있습니다.

## 실행

GitHub Pages를 켜면 웹에서 플레이할 수 있습니다.

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Deploy from a branch**를 선택합니다.
3. Branch를 **main**, 폴더를 **/(root)** 로 선택하고 저장합니다.
4. 배포가 완료되면 `https://egiby07.github.io/smash/` 에서 확인합니다.

Three.js는 jsDelivr CDN에서 불러오므로 플레이할 때 인터넷 연결이 필요합니다.

## 기술

- HTML / CSS
- JavaScript ES Modules
- Three.js r160
- GitHub Pages

이 프로젝트는 가상의 캠퍼스에서 파괴 효과를 즐기는 팬메이드 미니 게임입니다.
